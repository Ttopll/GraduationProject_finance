# miniapp-mvp

当前目录已经改造成用户端微信小程序 MVP，不再是之前那套“真实数据分析演示页”。

## 当前范围

- 登录页
- 家庭首页
- 账户总览
- 交易列表
- 新增交易
- 通知中心

## 依赖后端

默认连接本机后端：

- `http://127.0.0.1:8088`

如需修改，请编辑：

- `miniapp-mvp/app.js`

## 快速启动

1. 启动后端服务。
2. 用微信开发者工具导入 `miniapp-mvp`。
3. 在本地设置中关闭合法域名校验。
4. 使用已有账号登录。
5. 先验证：首页、账户、交易、记账、通知这 5 条主线。

## 说明

- 当前是小程序端第一版，目标是先把用户主闭环跑通。
- 后续再继续补页面精度、家庭操作、更多查询筛选和图表展示。
