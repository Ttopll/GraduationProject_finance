## 1. 本版验收目标

本版用于答辩前的“当前实现完成度”验收，重点覆盖两部分：

- 主链路闭环：注册登录 -> 家庭与权限 -> 账本核心 -> 规则评估 -> 通知 -> 账单导入与待归类闭环。
- 近期增强能力：多个模块的更新/启停用/删除等 mutation API，确认“可维护、可演示、可扩展”。

## 2. 建议验收顺序（答辩录屏顺序）

1. 认证与家庭初始化  
2. 账户、分类、预算  
3. 交易流水、余额联动、预算统计  
4. 债务与还款  
5. 规则定义、手动评估、通知  
6. 账单导入、待归类处理、重复导入拦截

## 3. 主链路必过清单

- [ ] 注册、登录、`/api/auth/me` 正常返回，JWT 鉴权生效。
- [ ] 家庭创建成功，成员关系正确，户主转交与成员退出流程可用。
- [ ] 账户、分类、预算可创建并可查询。
- [ ] 创建交易后，账户余额与预算统计同步联动。
- [ ] 债务创建、还款、提醒检查流程可用。
- [ ] 规则创建与手动评估成功，通知可生成并查询。

- [ ] 待归类处理后，第二轮导入可命中新规则自动归类。
- [ ] 重复上传同一文件被 `409 Conflict` 拦截。

## 4. 本阶段 mutation API 验收清单（新增）

### 4.1 账户

- [ ] `PUT /api/accounts/{id}`：账户信息可更新。
- [ ] `POST /api/accounts/{id}/disable`：可停用。
- [ ] `POST /api/accounts/{id}/enable`：可重新启用。
- [ ] `DELETE /api/accounts/{id}`：删除前引用校验有效（被交易/还款引用时拒绝）。

### 4.2 分类

- [ ] `PUT /api/categories/{id}`：分类可更新。
- [ ] `POST /api/categories/{id}/disable`：可停用。
- [ ] `POST /api/categories/{id}/enable`：可启用。
- [ ] `DELETE /api/categories/{id}`：引用保护生效。

### 4.3 预算

- [ ] `PUT /api/budgets/{id}`：预算可更新。
- [ ] `POST /api/budgets/{id}/disable`：停用后不参与统计。
- [ ] `POST /api/budgets/{id}/enable`：可恢复参与统计。
- [ ] `DELETE /api/budgets/{id}`：可删除并与查询结果一致。

### 4.4 规则定义与账单解析规则

- [ ] `GET /api/rules/{id}`、`PUT /api/rules/{id}`、`POST /api/rules/{id}/enable|disable`、`DELETE /api/rules/{id}` 全部可用。
- [ ] `GET /api/bill-parse-rules/{id}`、`PUT /api/bill-parse-rules/{id}`、`POST /api/bill-parse-rules/{id}/enable|disable`、`DELETE /api/bill-parse-rules/{id}` 全部可用。

### 4.5 通知

- [ ] `POST /api/notifications/read-all`：批量已读可用。
- [ ] `DELETE /api/notifications/{id}`：单条删除可用。
- [ ] `DELETE /api/notifications/read`：已读清理可用。
- [ ] `GET /api/notifications/search`：支持分页与筛选（`readStatus/sourceType/page/size`）。

### 4.6 固定资产、家庭财务画像、理财建议、数据导出

- [ ] 固定资产：单条查询、更新、启停用、删除可用。
- [ ] 家庭财务画像：重置（删除画像）可用。
- [ ] 理财建议：单条查询、标记未读、删除可用。
- [ ] 数据导出：单条查询、删除（含文件清理）可用。

### 4.7 认证增强

- [ ] `POST /api/auth/change-password`：旧密码校验通过后可修改密码，错误旧密码返回 `400`。

### 4.8 交易查询增强

- [ ] `GET /api/transaction-records/search`：支持分页（`page/size`）和筛选（`transactionType/startTime/endTime`）。

### 4.9 真实数据导入与分析

- [ ] `POST /api/real-data-analysis/import`：可将 `data/processed` 下真实数据 CSV 导入数据库。
- [ ] `GET /api/real-data-analysis/retail-overview`：可返回交易级真实数据总览与国家分布。
- [ ] `GET /api/real-data-analysis/world-bank-trend`：可返回宏观消费指标年度趋势与同比增速。
