# 最终功能完成度与演示验收清单

本文档用于毕业设计最终验收、论文撰写和答辩演示准备。项目定位为“基于规则引擎的家庭财务管理系统”，当前系统主要由后端服务、管理员后台和小程序端组成。后端负责业务规则、数据存储、接口和分析计算；管理员后台负责较完整的数据维护和管理；小程序端负责普通家庭用户的日常记账、预算、提醒、资产负债和理财建议查看。

## 四、推荐最终演示路线

### 路线一：核心家庭理财闭环

1. 登录管理员端或小程序端。
2. 选择当前家庭。
3. 新增账户，确认账户余额。
4. 新增分类，例如“餐饮”“交通”“工资”。
5. 新增预算，例如“餐饮月预算 1500 元”。
6. 新增一笔餐饮支出。
7. 打开预算页，查看预算使用率和预警状态。
8. 打开财务分析页，查看月报、健康评分、消费结构和处理建议。
9. 打开消费提醒页，设置或执行自动提醒。
10. 打开提醒中心，查看系统生成的预算/规则提醒。

### 路线二：资产负债与理财建议闭环

1. 打开资产负债页。
2. 新增固定资产，例如房产、车辆或定期存款。
3. 新增债务，例如房贷、信用卡或消费贷。
4. 记录一笔还款，查看债务余额变化。
5. 返回资产看板，查看总资产、净资产和负债率。
6. 打开理财画像，设置风险偏好、目标储蓄率和理财目标。
7. 打开理财建议页，生成本月建议。
8. 展示建议中的指标依据、执行步骤和跳转入口。

### 路线三：数据导入导出与真实数据分析

1. 打开管理员端“账单导入导出”。
2. 上传样例 CSV 账单，查看导入批次和待归类项目。
3. 对待归类项目进行分类，并生成解析规则。
4. 导出交易或预算数据，查看导出记录。
5. 打开“外部消费数据”页面。
6. 执行真实数据导入或查看历史导入结果。
7. 展示零售交易结构、国家消费趋势和答辩摘要。
