# Real Data Analysis API

## Purpose

Provide an end-to-end flow for:

1. Importing externally fetched real datasets into MySQL.
2. Querying analysis endpoints for thesis demo and report screenshots.

## Endpoints

- `POST /api/real-data-analysis/import`
- `GET /api/real-data-analysis/retail-overview`
- `GET /api/real-data-analysis/world-bank-trend`
- `GET /api/real-data-analysis/fred-series`

## 1) Import Processed CSV

```http
POST /api/real-data-analysis/import?processedDir=data/processed&truncateBeforeImport=true&batchSize=5000
Authorization: Bearer <accessToken>
```

Response:

```json
{
  "processedDir": "C:\\Users\\Ttop\\codex_tmp_finance_verify_20260309_1\\data\\processed",
  "truncatedBeforeImport": true,
  "retailImported": 530104,
  "worldBankImported": 137,
  "fredImported": 0
}
```

## 2) Retail Overview

```http
GET /api/real-data-analysis/retail-overview?topCountries=10
Authorization: Bearer <accessToken>
```

Returns total records, total amount, average amount, invoice time range and top countries by amount.

## 3) World Bank Trend

```http
GET /api/real-data-analysis/world-bank-trend?countryIso3=CHN
Authorization: Bearer <accessToken>
```

Returns yearly value and year-on-year growth ratio.

## 4) FRED Series

```http
GET /api/real-data-analysis/fred-series?seriesId=PCE
Authorization: Bearer <accessToken>
```

Returns imported points. If local environment cannot fetch FRED successfully, this list may be empty.
