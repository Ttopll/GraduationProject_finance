# 真实数据分析接口说明

## 作用

这一组接口用于完成以下链路：

1. 将外部抓取并清洗后的真实数据导入 MySQL。
2. 查询零售交易、World Bank、FRED 的真实分析结果。
3. 为管理员端导入中心提供可持久化的导入历史。
4. 为答辩演示和阶段汇报提供可直接截图的分析输出。

## 接口总览

- `POST /api/real-data-analysis/import`
- `GET /api/real-data-analysis/imports`
- `GET /api/real-data-analysis/retail-overview`
- `GET /api/real-data-analysis/world-bank-trend`
- `GET /api/real-data-analysis/fred-series`
- `GET /api/real-data-analysis/defense-summary`

## 1. 导入真实数据

```http
POST /api/real-data-analysis/import?processedDir=data/processed&truncateBeforeImport=true&batchSize=5000
Authorization: Bearer <accessToken>
```

说明：

- `processedDir`：处理后数据目录，默认 `data/processed`
- `truncateBeforeImport`：是否在导入前清空三张真实数据表
- `batchSize`：分批写库大小，建议 1000 到 10000

响应示例：

```json
{
  "importBatchId": 7,
  "processedDir": "C:\\Users\\Ttop\\codex_tmp_finance_verify_20260309_1\\data\\processed",
  "batchSize": 5000,
  "truncatedBeforeImport": true,
  "retailImported": 530104,
  "worldBankImported": 137,
  "fredImported": 0,
  "importStatus": "SUCCESS",
  "importedAt": "2026-04-20T20:31:10"
}
```

## 2. 查询导入历史

```http
GET /api/real-data-analysis/imports
Authorization: Bearer <accessToken>
```

说明：

- 返回最近 20 条导入批次记录
- 用于管理员端“导入管理”页面持久化展示
- 页面刷新后仍可查看历史，不再依赖前端内存

响应示例：

```json
[
  {
    "id": 7,
    "processedDir": "C:\\Users\\Ttop\\codex_tmp_finance_verify_20260309_1\\data\\processed",
    "batchSize": 5000,
    "truncatedBeforeImport": true,
    "retailImported": 530104,
    "worldBankImported": 137,
    "fredImported": 0,
    "importStatus": "SUCCESS",
    "importedAt": "2026-04-20T20:31:10",
    "createdAt": "2026-04-20T20:31:10"
  }
]
```

## 3. 查询零售概览

```http
GET /api/real-data-analysis/retail-overview?topCountries=10
Authorization: Bearer <accessToken>
```

返回内容包括：

- 零售总记录数
- 零售总金额
- 平均交易金额
- 最早与最晚发票时间
- 按交易额排序的国家 Top 列表

## 4. 查询 World Bank 国家趋势

```http
GET /api/real-data-analysis/world-bank-trend?countryIso3=CHN
Authorization: Bearer <accessToken>
```

返回内容包括：

- 国家 ISO3
- 国家名称
- 各年份指标值
- 年同比增长比率

## 5. 查询 FRED 序列

```http
GET /api/real-data-analysis/fred-series?seriesId=PCE
Authorization: Bearer <accessToken>
```

返回内容包括：

- 序列 ID
- 本地已导入的数据点列表

说明：

- 如果当前环境没有成功抓到 FRED，可能返回空列表
- 这属于已设计的软降级行为，不影响其余真实数据分析链路

## 6. 一次性查询答辩汇总

```http
GET /api/real-data-analysis/defense-summary?countryIso3=CHN&seriesId=PCE&topCountries=10
Authorization: Bearer <accessToken>
```

返回内容包括：

- `retailOverview`
- `worldBankTrend`
- `fredSeries`
- `conclusions`

说明：

- `conclusions` 为自动生成的中文结论，可直接用于答辩页、管理员端、阶段汇报
- 当前已经包含国家趋势结论、交易结构结论、FRED 状态结论
