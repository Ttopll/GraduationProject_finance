## 四、推荐演示路线

### 1. 登录与总控台

1. 打开 `http://localhost:5173`。
2. 使用 `demo_owner / Demo123456` 登录。
3. 展示总控台中的收入、支出、净资产、预算风险、规则命中和通知概览。
4. 说明管理员端不是静态页面，数据来自后端接口和数据库。

### 2. 业务数据管理

1. 进入“业务数据管理”。
2. 展示账户列表，说明系统支持现金、银行卡、信用卡等家庭账户管理。
3. 展示分类列表，说明交易可以按照收入和支出分类。
4. 展示预算列表，说明预算有使用率、预警比例和状态标签。
5. 展示交易列表，说明交易会影响账户余额和预算统计。

### 3. 规则与通知

1. 进入“规则与通知”。
2. 展示规则列表，说明系统可配置预算超额、连续高支出、消费异常等规则。
3. 点击“执行规则评估”。
4. 展示规则执行日志和通知中心。
5. 说明项目的核心闭环是“业务数据 -> 规则评估 -> 生成通知 -> 两端查看”。

### 4. 真实数据分析

1. 进入“真实数据分析”。
2. 展示真实数据导入区域。
3. 展示零售交易概览，说明当前已导入 530104 行 Online Retail 交易数据。
4. 展示 World Bank 国家趋势，建议使用 `CHN`。
5. 展示 FRED 序列区域，说明当前 FRED 因数据源网络失败保留了空文件和软降级处理。

### 5. 小程序端联通

1. 用微信开发者工具打开 `miniapp-mvp`。
2. 使用 `demo_owner / Demo123456` 登录。
3. 进入家庭首页、账户、交易、预算、通知页面。
4. 说明小程序端和管理员端使用同一套后端接口、同一个数据库，因此能看到同一家庭下的数据。

## 五、演示说明话术

```text
本项目是一个基于规则引擎的家庭财务管理系统，分为管理员端和小程序端。管理员端主要用于家庭财务数据维护、规则配置、通知管理和真实数据分析，小程序端面向普通家庭成员使用。系统后端使用 Spring Boot 提供统一接口，数据库使用 MySQL 保存用户、家庭、账户、交易、预算、规则、通知以及外部真实数据。

目前项目已经完成登录认证、家庭上下文、账户分类、预算交易、规则评估、通知生成、真实数据导入分析以及两端联通。项目核心是规则引擎闭环：系统根据家庭交易和预算数据执行规则判断，命中后生成通知，管理员端和小程序端都可以查看结果。
```
