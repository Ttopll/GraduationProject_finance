# Account Mutation API

## Endpoints

- `PUT /api/accounts/{accountId}`
- `POST /api/accounts/{accountId}/enable`
- `POST /api/accounts/{accountId}/disable`
- `DELETE /api/accounts/{accountId}`

## Permission Rule

- Admin can manage all accounts.
- Family owner can manage all accounts in the family.
- Account owner member can manage their own account.

## Delete Example

```http
DELETE /api/accounts/10
Authorization: Bearer <accessToken>
```

Response:

```http
204 No Content
```

## Delete Guard Rules

Delete will be rejected with `409 Conflict` when:

- The account is referenced as `accountId` or `targetAccountId` in transaction records.
- The account is referenced as `payAccountId` in debt repayments.
