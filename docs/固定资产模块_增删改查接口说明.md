# Fixed Asset Mutation API

## Endpoints

- `GET /api/fixed-assets/{assetId}`
- `PUT /api/fixed-assets/{assetId}`
- `POST /api/fixed-assets/{assetId}/enable`
- `POST /api/fixed-assets/{assetId}/disable`
- `DELETE /api/fixed-assets/{assetId}`

## Permission Rule

- Admin can manage all fixed assets.
- Family owner can manage all fixed assets in family.
- Asset owner member can manage their own fixed assets.

## Update Request Example

```http
PUT /api/fixed-assets/100
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "ownerMemberId": 12,
  "assetName": "Family Car",
  "assetType": "CAR",
  "purchaseAmount": 120000.00,
  "purchaseDate": "2024-05-01",
  "valuationAmount": 98000.00,
  "valuationDate": "2026-04-01",
  "remark": "updated for defense demo"
}
```

## Delete Example

```http
DELETE /api/fixed-assets/100
Authorization: Bearer <accessToken>
```

Response:

```http
204 No Content
```
