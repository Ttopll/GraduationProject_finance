# 项目进度总结（2026-04-08）

## 1. 当前总体状态

当前后端已经从“可演示核心链路”推进到“核心链路 + 主要模块可维护”的阶段。  
除登录鉴权、家庭权限、账单导入、规则评估等主链路外，近期重点补齐了多个模块的增改查删与启停用能力，便于答辩演示和后续扩展。

## 2. 已完成的主链路能力

- 认证与权限：注册、登录、JWT、家庭成员权限校验。
- 家庭账本核心数据流：账户、分类、预算、交易流水、债务、通知。
- 账单导入闭环：CSV 导入、自动分类、待归类处理、重复导入拦截。
- 规则引擎闭环：规则定义、手动评估、执行日志、通知联动。

## 3. 本阶段新增增强（你最近几轮开发）

- 分类模块：新增更新、启用、停用、删除；删除增加引用保护。
- 预算模块：新增删除接口。
- 账户模块：新增删除接口；删除前校验交易/还款引用。
- 规则定义模块：新增单条查询、更新、启停用、删除；校验逻辑统一。
- 账单解析规则模块：新增单条查询、更新、启停用、删除。
- 通知模块：新增批量已读、单条删除、已读清理。
- 固定资产模块：新增单条查询、更新、启停用、删除，补管理权限控制。
- 家庭财务画像模块：新增重置（删除画像）能力。
- 理财建议模块：新增单条查询、标记未读、删除。
- 数据导出模块：新增单条查询、删除（含导出文件清理）。
