# Data Export Mutation API

## Endpoints

- `GET /api/data-exports/{exportId}`
- `DELETE /api/data-exports/{exportId}`

## Permission Rule

- Family readable members can query and delete export logs in their family scope.

## Get Example

```http
GET /api/data-exports/10
Authorization: Bearer <accessToken>
```

## Delete Example

```http
DELETE /api/data-exports/10
Authorization: Bearer <accessToken>
```

Response:

```http
204 No Content
```

## Behavior Notes

- Delete attempts to remove the exported file on disk first, then removes the export log.
- If the file is already missing, log deletion still succeeds.
