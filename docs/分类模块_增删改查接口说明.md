# Category Mutation API

## Endpoints

- `PUT /api/categories/{categoryId}`
- `POST /api/categories/{categoryId}/enable`
- `POST /api/categories/{categoryId}/disable`
- `DELETE /api/categories/{categoryId}`

## Permission Rule

- Only family owner can update, enable, disable, or delete a category.

## Update Request Example

```http
PUT /api/categories/10
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "parentId": null,
  "categoryName": "Dining",
  "categoryType": "EXPENSE",
  "scopeType": "FAMILY",
  "iconCode": "food",
  "sortOrder": 1
}
```

## Enable / Disable Example

```http
POST /api/categories/10/disable
Authorization: Bearer <accessToken>
```

```http
POST /api/categories/10/enable
Authorization: Bearer <accessToken>
```

## Delete Example

```http
DELETE /api/categories/10
Authorization: Bearer <accessToken>
```

Response:

```http
204 No Content
```

## Delete Guard Rules

Delete will be rejected with `409 Conflict` when any of the following exists:

- Child categories under this category
- Budgets referencing this category
- Transaction records referencing this category
- Rule definitions referencing this category
- Bill parse rules referencing this category
