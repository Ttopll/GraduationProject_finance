# Financial Advice Mutation API

## Endpoints

- `GET /api/financial-advices/{adviceId}`
- `POST /api/financial-advices/{adviceId}/read`
- `POST /api/financial-advices/{adviceId}/unread`
- `DELETE /api/financial-advices/{adviceId}`

## Permission Rule

- Family readable members can get and mark advice read or unread.
- Family readable members can delete advice they are allowed to access.

## Mark Unread Example

```http
POST /api/financial-advices/100/unread
Authorization: Bearer <accessToken>
```

## Delete Example

```http
DELETE /api/financial-advices/100
Authorization: Bearer <accessToken>
```

Response:

```http
204 No Content
```
