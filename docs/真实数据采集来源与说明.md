# 真实数据抓取与清洗说明

更新时间：2026-04-08

## 1. 目标

为毕设数据分析模块提供“可复现、可追溯、非手工拼凑”的真实数据来源，并输出统一清洗结果。

## 2. 已提供脚本

- 脚本路径：`scripts/fetch_real_data.ps1`
- 输出目录：
  - 原始数据：`data/raw`
  - 清洗数据：`data/processed`

## 3. 数据源（真实公开数据）

### 3.1 交易级真实数据（Online Retail）

- 来源：Online Retail 公共数据镜像（原始数据来自 UCI 常用零售交易数据）
- 脚本输出：`data/processed/online_retail_transactions.csv`
- 主要字段：`invoice_no`, `quantity`, `unit_price`, `amount`, `invoice_time`, `country`

### 3.2 宏观消费指标（World Bank）

- 指标：`NE.CON.PRVT.PC.KD`（按人均最终消费支出，常量美元）
- 脚本输出：`data/processed/world_bank_household_consumption.csv`

### 3.3 宏观时间序列（FRED）

- 系列：`PCE`, `CPIAUCSL`
- 脚本输出：`data/processed/fred_macro_series.csv`

## 4. 执行方式

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\fetch_real_data.ps1
```

可选参数：

```powershell
# 仅抓宏观数据
powershell -ExecutionPolicy Bypass -File .\scripts\fetch_real_data.ps1 -SkipOnlineRetail

# 指定国家（World Bank）
powershell -ExecutionPolicy Bypass -File .\scripts\fetch_real_data.ps1 -Countries "CHN,USA,GBR"
```

## 5. 数据使用建议（答辩口径）

- `online_retail_transactions.csv`：用于规则命中演示、异常消费检测、聚类/分群分析。
- `world_bank_household_consumption.csv` + `fred_macro_series.csv`：用于趋势背景分析和外部环境解释。
- 分析报告中建议明确标注 `source_dataset`，保持数据血缘可追溯。

## 6. 合规边界

- 仅使用公开可访问数据源。
- 不抓取需要登录、验证码、绕过授权的数据。
- 如果某平台更新条款，需以最新条款为准。
