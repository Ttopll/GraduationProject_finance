# 一键三端联通验收脚本说明

文件：`scripts/run_three_end_mvp_acceptance.ps1`

## 作用

自动完成以下流程：

1. 启动后端服务
2. 等待服务就绪
3. 调用验收报告脚本生成 Markdown 报告
4. 自动停止后端服务

## 推荐用法

```powershell
pwsh -File scripts/run_three_end_mvp_acceptance.ps1 -AutoCreateUser
```

## 使用已有账号

```powershell
pwsh -File scripts/run_three_end_mvp_acceptance.ps1 -Username your_user -Password your_password
```

## 输出结果

- 控制台输出 JSON（含 `reportPath`）
- 报告文件写入：`docs/reports`

## 适用场景

- 答辩前快速回归
- 每天开发后做一次可复现验收
