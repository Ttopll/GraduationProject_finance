# Family Financial Profile Mutation API

## Endpoints

- `PUT /api/family-financial-profile`
- `DELETE /api/family-financial-profile?familyId={familyId}`

## Permission Rule

- Family owner can save or reset family financial profile.

## Save Request Example

```http
PUT /api/family-financial-profile
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "familyId": 1,
  "riskPreference": "MEDIUM",
  "savingsTargetRate": 0.30,
  "emergencyFundMonths": 6,
  "investmentPreferenceJson": "{\"style\":\"balanced\"}"
}
```

## Reset Example

```http
DELETE /api/family-financial-profile?familyId=1
Authorization: Bearer <accessToken>
```

Response:

```json
{
  "familyId": 1,
  "affectedCount": 1
}
```

## Behavior Notes

- After reset, `GET /api/family-financial-profile?familyId=1` returns default profile with `riskPreference = LOW`.
