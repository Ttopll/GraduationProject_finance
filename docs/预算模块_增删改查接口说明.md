# Budget Mutation API

## Endpoints

- `PUT /api/budgets/{budgetId}`
- `POST /api/budgets/{budgetId}/enable`
- `POST /api/budgets/{budgetId}/disable`
- `DELETE /api/budgets/{budgetId}`

## Permission Rule

- Any readable family member can update, enable, disable, or delete a budget.

## Delete Example

```http
DELETE /api/budgets/10
Authorization: Bearer <accessToken>
```

Response:

```http
204 No Content
```

## Notes

- Deleting a budget only removes budget plan data.
- Existing transaction records are not deleted.
