# Auth Change Password API

## Endpoint

- `POST /api/auth/change-password`

## Purpose

Allow logged-in users to update their own password safely by verifying the old password first.

## Auth

- Requires JWT: `Authorization: Bearer <accessToken>`

## Request Example

```http
POST /api/auth/change-password
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "oldPassword": "OldPass123",
  "newPassword": "NewPass123"
}
```

## Response

Success:

```http
204 No Content
```

## Validation Rules

- `oldPassword` must match current user password, otherwise `400 Bad Request`.
- `newPassword` length must be `8-64`.
- `newPassword` cannot be the same as `oldPassword`.

## Error Examples

- `400 Bad Request`: old password is wrong.
- `400 Bad Request`: new password is the same as old password.
- `401 Unauthorized`: token is missing or invalid.
