# Bill Parse Rule Mutation API

## Endpoints

- `GET /api/bill-parse-rules/{ruleId}`
- `PUT /api/bill-parse-rules/{ruleId}`
- `POST /api/bill-parse-rules/{ruleId}/enable`
- `POST /api/bill-parse-rules/{ruleId}/disable`
- `DELETE /api/bill-parse-rules/{ruleId}`

## Permission Rule

- Family owner can query, update, enable, disable, and delete bill parse rules.

## Update Request Example

```http
PUT /api/bill-parse-rules/100
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "categoryId": 3,
  "merchantKeyword": "STARBUCKS",
  "regexPattern": null,
  "priority": 10
}
```

## Delete Example

```http
DELETE /api/bill-parse-rules/100
Authorization: Bearer <accessToken>
```

Response:

```http
204 No Content
```
