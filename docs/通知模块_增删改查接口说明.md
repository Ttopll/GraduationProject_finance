# Notification Mutation API

## Endpoints

- `POST /api/notifications/{notificationId}/read`
- `POST /api/notifications/read-all`
- `DELETE /api/notifications/{notificationId}`
- `DELETE /api/notifications/read`
- `GET /api/notifications/search`

## Permission Rule

- Family members can operate on notifications they can read.
- Family owner and admin can operate on broader notification scope.

## Mark All Read Example

```http
POST /api/notifications/read-all?familyId=1
Authorization: Bearer <accessToken>
```

Optional member scope:

```http
POST /api/notifications/read-all?familyId=1&targetMemberId=12
Authorization: Bearer <accessToken>
```

Response:

```json
{
  "affectedCount": 5
}
```

## Delete Read Notifications Example

```http
DELETE /api/notifications/read?familyId=1
Authorization: Bearer <accessToken>
```

Response:

```json
{
  "affectedCount": 3
}
```

## Search Example

```http
GET /api/notifications/search?familyId=1&readStatus=0&sourceType=RULE&page=0&size=20
Authorization: Bearer <accessToken>
```

Response fields:

- `items`: current page notifications.
- `page`: page index (0-based).
- `size`: page size.
- `totalElements`: total matched records.
- `totalPages`: total pages.
