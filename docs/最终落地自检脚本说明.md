# 最终落地自检脚本说明

脚本：`scripts/run_final_landing_check.ps1`

## 作用

用于 5 月 5 日前快速检查项目是否具备落地演示基础，重点覆盖：

- 项目关键目录和配置是否存在
- 真实数据文件是否存在
- 管理员端 Vue 页面是否能解析
- 小程序 `app.json` 注册页面文件是否完整
- 可选检查后端服务是否启动
- 可选检查真实数据导入和分析接口

## 默认自检

不要求后端启动，不会导入 53 万行真实数据，适合每天开发后快速跑一次。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_final_landing_check.ps1
```

通过标准：`failedCount` 为 `0`。

## 检查后端是否启动

需要先在 IDEA 或终端启动 Spring Boot。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_final_landing_check.ps1 -CheckBackend
```

## 检查真实数据接口

需要后端已启动，并且提供可登录账号。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_final_landing_check.ps1 `
  -CheckBackend `
  -CheckRealDataApis `
  -Username admin_tqc `
  -Password 12345678
```

如果不想使用已有账号，可以让脚本自动创建测试账号：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_final_landing_check.ps1 `
  -CheckBackend `
  -CheckRealDataApis `
  -AutoCreateUser
```

## 注意事项

- 默认 `TruncateBeforeImport` 为 `false`，避免每次自检都清空并重导真实数据。
- 如果需要完全重导真实数据，可以加 `-TruncateBeforeImport $true`。
- 真实数据导入数据量较大，执行时间会明显长于默认自检。
