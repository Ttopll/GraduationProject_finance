# 最终落地自检脚本说明

脚本：`scripts/run_final_landing_check.ps1`

## 作用

该脚本用于在项目收尾阶段快速确认系统是否具备演示和交付基础，重点检查：

- 项目关键目录、配置文件是否存在
- 真实数据文件是否存在
- 管理员端 Vue 页面是否能被解析
- 小程序 `app.json` 中注册的页面文件是否完整
- 后端服务是否已经启动
- 真实数据导入和分析接口是否可用

## 快速自检

不要求后端启动，不会调用真实数据导入接口，适合日常开发后快速跑一次。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_final_landing_check.ps1
```

通过标准：输出中的 `failedCount` 为 `0`。

## 检查后端是否启动

先在 IDEA 或终端启动 Spring Boot 后端，再执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_final_landing_check.ps1 -CheckBackend
```

## 检查真实数据导入与分析接口

该命令会登录账号、执行真实数据导入，并验证零售概览、World Bank 趋势、FRED 序列接口。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_final_landing_check.ps1 `
  -CheckBackend `
  -CheckRealDataApis `
  -Username demo_owner `
  -Password Demo123456
```

注意：脚本默认使用 `TruncateBeforeImport=true`，也就是先清空三张真实数据表再重新导入，避免反复自检造成数据重复。

如果只想增量导入，可以显式传入：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_final_landing_check.ps1 `
  -CheckBackend `
  -CheckRealDataApis `
  -Username demo_owner `
  -Password Demo123456 `
  -TruncateBeforeImport:$false
```

## 执行耗时

真实数据中零售交易约 53 万行，完整导入通常需要数分钟。看到 IDEA 控制台持续输出 `insert into external_retail_transaction` 属于正常现象，等待脚本最终输出 JSON 结果即可。
