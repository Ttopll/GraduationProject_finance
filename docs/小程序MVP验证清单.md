# 小程序 MVP 验证清单

更新时间：2026-04-27

适用目录：`miniapp-mvp`

## 1. 验证前准备

1. 启动后端：`mvn spring-boot:run`（端口 `8088`）。
2. 确保已有可登录用户，且该用户至少已加入一个家庭。
3. 微信开发者工具导入 `miniapp-mvp`。
4. 打开「本地设置」并勾选：不校验合法域名、web-view、TLS 版本及 HTTPS 证书。

## 2. 功能验证（第一轮必须通过）

1. 打开小程序后默认进入登录页。
2. 输入正确账号密码，点击“登录并进入首页”。
3. 预期：进入“家庭首页”。
4. 预期：首页展示当前家庭、账户数、账户余额、净资产、未读通知。
5. 点击“查看账户”，进入账户总览页。
6. 预期：账户列表能显示账户名称、类型、余额、状态。
7. 点击“查看交易”，进入交易列表页。
8. 预期：交易列表能显示最近交易。
9. 点击“新增交易”，进入记账页。
10. 选择账户、填写金额、选择时间并提交。
11. 预期：提示“已记账”，返回交易列表后能看到新交易。
12. 点击“查看通知”，进入通知中心。
13. 预期：通知能正常拉取，未读通知可设为已读。
14. 从首页切换家庭（若当前账号有多个家庭）。
15. 预期：首页、账户、交易、通知的数据范围随家庭一起切换。

## 3. 异常验证（建议通过）

1. 错误密码登录：页面出现“登录失败”。
2. 当前账号没有家庭：首页提示“当前账号还没有家庭上下文”。
3. 后端停机后刷新页面：页面出现“加载失败”。
4. 清除 storage 后重新打开业务页：应回到登录页。

## 4. 当前判定标准

- 登录成功率 100%。
- `/api/auth/login`、`/api/auth/me`、`/api/accounts`、`/api/transaction-records/search`、`/api/transaction-records`、`/api/notifications/search` 返回正常。
- 小程序展示的数据来自真实后端，不是 mock。
- 至少完成“登录 -> 首页 -> 交易列表 -> 新增交易 -> 列表回看”这一条主闭环。

## 5. 当前阶段说明

- 这一版是用户端 MVP 第一轮。
- 目标是先把用户主业务闭环跑通，不是一次性把所有页面做满。
- 后续可以继续补：家庭管理、分类视图、预算提醒、个人资产页、图表展示。
