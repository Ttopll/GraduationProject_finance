# 小程序 MVP 验证清单

更新时间：2026-04-19

适用目录：`miniapp-mvp`

## 1. 验证前准备

1. 启动后端：`mvn spring-boot:run`（端口 8088）。
2. 确保已有可登录用户（可用 `/api/users` 创建）。
3. 微信开发者工具导入 `miniapp-mvp`。
4. 打开「本地设置」并勾选：不校验合法域名、web-view、TLS 版本及 HTTPS 证书。

## 2. 功能验证（必须通过）

1. 打开小程序后默认进入登录页。
2. 输入正确账号密码，点击登录。
3. 预期：跳转到 `Retail Overview` 页面。
4. 预期：页面显示 `totalRecords`、`totalAmount`、`topCountries`。
5. 点击“查看国家趋势”，进入 `World Bank Trend` 页面。
6. 默认 `CHN` 点击查询，预期显示起始年、最新年、最新同比。
7. 点击“查看FRED”，进入 `FRED Series` 页面。
8. 默认 `PCE` 点击查询，预期显示“数据点数量”。
9. 若点数为 0，显示“抓取软降级”提示也视为通过。
10. 返回并退出，回到登录页。

## 3. 异常验证（建议通过）

1. 错误密码登录：页面出现 `登录失败: HTTP 401`。
2. 后端停机后刷新：页面出现 `加载失败`。
3. 清除 storage 后打开分析页：应重定向回登录页。

## 4. 联通性验证（答辩可展示）

1. 在后台 `admin-mvp.html` 执行导入。
2. 在后台依次查询 3 个接口并生成自动结论。
3. 回到小程序点击刷新，确认零售总览与后台一致。

## 5. 判定标准

- 登录成功率 100%。
- `retail-overview`、`world-bank-trend`、`fred-series` 请求返回 200。
- 页面展示为真实后端数据，不是 mock。
