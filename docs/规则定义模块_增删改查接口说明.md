# Rule Definition Mutation API

## Endpoints

- `GET /api/rules/{ruleId}`
- `PUT /api/rules/{ruleId}`
- `POST /api/rules/{ruleId}/enable`
- `POST /api/rules/{ruleId}/disable`
- `DELETE /api/rules/{ruleId}`

## Permission Rule

- Family owner can update, enable, disable, delete, and evaluate rule definitions.
- Family readable members can query a single rule and list rules.

## Update Request Example

```http
PUT /api/rules/100
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "categoryId": 3,
  "createdByMemberId": 5,
  "ruleName": "Dining threshold rule",
  "ruleType": "THRESHOLD",
  "metricType": "CATEGORY_EXPENSE",
  "timeScope": "MONTH",
  "operatorType": "GTE",
  "thresholdValue": 500.00,
  "thresholdJson": null,
  "actionType": "NOTIFY",
  "messageTemplate": "Dining expense reached threshold",
  "priority": 20
}
```

## Delete Example

```http
DELETE /api/rules/100
Authorization: Bearer <accessToken>
```

Response:

```http
204 No Content
```
