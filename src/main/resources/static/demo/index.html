建议演示顺序

  1. 登录并切换到目标家庭与成员。
  2. 展示月度收支、净资产、预算预警和支出结构。
  3. 新增一条交易流水，再演示编辑与删除。
  4. 新增债务，记录一次还款，再演示结清或删除。
